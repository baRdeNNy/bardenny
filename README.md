## 🚀 Proyectos destacados

### [🖥️ homelab-pyme](https://github.com/baRdeNNy/homelab-pyme)
Infraestructura completa de una pyme montada sobre **Proxmox VE**: firewall perimetral **FortiGate-VM** con LAN y DMZ separadas, controlador de dominio **Windows Server 2025** (AD, DNS, DHCP), servidor **Ubuntu + Docker** en la DMZ publicado con VIP y backups con **Acronis Cyber Protect**. Incluye un script en Python que hace backup diario de la configuración del FortiGate y genera un informe de estado de Proxmox, usando tokens de API de mínimo privilegio. Cada fase está documentada paso a paso.

### [📦 CES · Control d'Estoc amb Sensors](https://github.com/baRdeNNy/sintesiASIX)
Proyecto de síntesis de ASIX (Institut de l'Ebre, 2021). Sistema IoT con **Raspberry Pi** que mide el stock, la temperatura y la humedad de máquinas de vending, con panel web en **Laravel**, base de datos **MySQL**, app **Android**, bastionado del equipo (SSH, Fail2Ban) y backups automáticos a Google Drive. [📖 Documentación completa](https://bardenny.github.io/sintesiASIX/)
